# Surface brief: demo 对比页（demo/public/index.html）

## Scope and mode

Operate。单页工具：外部访客第一次来，配置 key → 输入/选示例 → 标注 → 两栏对听 → 下载/历史。桌面优先，手机能用。

## Audience, job, constraints

- 访客要一眼看清 skill 加了哪些标签、改了哪些字句，读懂标注策略，再用耳朵验证。
- 不能太冷（开发者控制台感）、太花、回到米色+衬线的复古、或像通用 AI 模板（渐变紫、玻璃卡片）。
- 保留全部现有功能：两家 TTS 设置与模型 datalist、标注引擎切换、max tokens、两栏标注/原文开关、手动编辑文本、流式标注、策略说明、生成/停止/下载、各引擎 5 条历史、隐私说明、localStorage 持久化。

## Direction contract

> 2026-11 第二次改版。原方向「语音消息」（seed:43c646320bd83afa）由用户在看过成品后主动替换为下面的「耳机」方向，配色换成用户提供的 Aurora 灰调色板。

THESIS: 同一段话，听两个版本：把"换耳机听另一边"直接画出来。拒绝深色波形 playground、米色纸张复古、通用 AI 渐变紫。

OWN-WORLD: Aurora 灰调：灰米底 #EDE6E1 上四角大面积径向晕染（砂岩、珍珠白、陶土、玫瑰），卡片和气泡是实色。唯一操作色檀木红 #7A4544，只给发送、生成、播放、进度。标签四色：情绪（玫瑰）、停顿呼吸（砂岩）、音色语调（陶土）、动作（灰青，调色板外补色）。Figtree + Noto Sans SC，自绘线性 SVG 图标。

STORY: 访客在模糊手机上那只清晰的气泡里写字（或点示例），点发送；右边 Fish Audio 卡里流式出现带标签胶囊的标注文本；鼠标移到哪张卡，耳机就换到哪张卡两侧，另一张退后；点播放对听，下方 Notes 分条解释为什么这样标。

FIRST VIEWPORT: 顶栏只有小号品牌名和设置胶囊（首次访问不自动展开，页面一打开就显示标注好的「口非心是」示例：文字 + Notes，没有预生成语音）。下面是 1400×800 舞台：左侧模糊手机 + 400px 宽输入气泡 + 示例菜单；右侧两张 330×520 输出卡（引擎名、模型、标注/原文两段开关、文本、编辑、进度条、重新生成/播放/下载）；耳机挂在选中卡两侧，耳机线连回手机。用户要求：不出现多余说明文字（图例、区块标题都去掉了）。

FORM: 用户自己画的草图（手机 + 两张 iPhone 音频页 + 有线耳机），由用户提供参考图逐轮修正。Signature move：耳机换边——朝哪边走哪边先动，停在挂点外上方，定一下，再沿斜线慢慢挂住，不回弹（用户明确否掉了 Q 弹的弹簧回弹）。耳机造型按 EarPods 参考图：切面有厚度、柄等宽、出音孔在远离切面一侧。

FINISH: 截图核对桌面 / 深色 / 平板 / 手机四种状态；DESIGN.md 与 design.json 已同步。
